# Userspace

Planned first tools:

- `msxng-info` - hardware/driver status.
- `msxng-legacy` - start/stop/reset/mount ROM/DSK/fullscreen/window.
- `msxng-gpu-test` - plane/scaling/alpha test.
- `msxng-memtest` - DMA/shared-memory stress helper.

A later desktop shell can integrate the legacy machine as a first-class application.
