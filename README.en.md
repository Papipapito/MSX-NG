# MSX-NG - English summary

MSX-NG is a specification-first FPGA computer architecture combining a Linux-capable **soft RV32 CPU**, a native 2D graphics/compositor subsystem and a hardware **Z80 + V9968 legacy MSX island**. The main reference target is Tang Console 138K, while the mandatory architecture deliberately avoids relying on the GW5AST hard RISC-V so it can later be ported to 60K-class Gowin parts or the PL of a Zynq-7020.
